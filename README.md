# Romme 1300 — Code source

Site statique complet : 6 pages HTML, styles CSS et JavaScript intégrés, images et polices locales dans assets/.

## Aperçu
Ouvrir index.html dans un navigateur ou lancer dans ce dossier :

    python3 -m http.server 8000

Puis consulter http://localhost:8000.

## Publication sur Vercel
Importer ce dossier comme projet statique (Framework : Other). Aucun build ni installation requis. Le dossier de sortie est la racine du projet. Avec la CLI Vercel connectée :

    vercel --prod

## Modification
Les textes, styles et scripts sont modifiables dans chaque fichier HTML. Les images sont dans assets/. Les crédits et sources sont indiqués sur le site.

Ce dossier ne contient aucun identifiant, token ou accès de compte.
